Manual Control

MANCTRL via rx_data. Direction codes 1-12 (joystick positions). Commands run until next command. Start manual mode first!

Hold to drive, release to send ANGLE:0 (stop). Press Start Manual first!

Console (rx_data)

Send any QLRPDataItem command. cmd is UPPERCASE for rx_data path.

Waiting for commands...

These go via opcode 0x0402 (app path). cmd is UPPERCASE. Separate from smart speaker commands.

Cleaning Modes (Handle_Robot_Ctrl — any non-numeric cmd hits case 0)
Non-numeric cmd strings (ZIGZAG, SPOT, etc) all map to case 0 via atoi()=0. Case 0 then checks the data field. Internally references "planning A2B", "planning spiral", "ANGLE:%d".
cmd="ZIGZAG" data=""Confirmed OK! Starts zigzag clean (no mapping)
cmd="SPOT" data=""Try: spot clean? (case 0 has "planning spiral")
cmd="A2B" data="x,y"Try: go-to-point? ("planning A2B, x:, y:")
cmd="RECHARGE" data=""Try: return to dock?
cmd="RESTART_CLEAN" data=""Restart cleaning (in rx_data cmd table)

Data field format
The data field is a string. For MANCTRL: S/E/K for mode, or ANGLE:N where N is a direction code (0-12). Commands run continuously until the next command. ANGLE:0 = joystick centre = stop. Speed is manual_wheel_speed: 8.0 from config. For MANBLOWER: LOW/MIDDLE/HIGHT/CLOSE.
