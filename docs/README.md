These notes describe one rooted EU Lucy on the firmware she came with. Other robots may differ. Findings are marked where they're unconfirmed.

Almost everything here needs root SSH access. The [rooting guide](../Getting_root_on_lucy.md) explains how to get it. The basic local server doesn't need root.
